## 最初の簡単なプログラム
**メッセージボックスで Hello, World! を表示するだけ**、という非常に簡単なプログラムを書いてみますが、追加の設定等の仕方が分かるので、なかなか面白いと思います。

まず、cargo を使って、プロジェクトを１つ作りましょう。\
下の例では `rust-test` としていますが、他の適当な名前でオッケーです。

```
> cargo init rust-test
```
\
`cargo init` で `main.rs` が作成されるので、それをちょっと書きかえてみましょう。

```Rust
fn main() {
	let title = "rust-test\0";
	let message = "Hello, World!\0";
	unsafe {
		MessageBoxA(std::ptr::null_mut(), message.as_ptr(), title.as_ptr(), MB_OK);
	}
}
```
<br>

`MessageBoxA()` は Windows API で、Windows API について調べたいときは、Google などで `Win32 MessageBoxA` のように検索すれば、すぐにヒットします。
`MessageBoxA()` を検索すると、次のページがヒットすると思います。\
https://learn.microsoft.com/ja-jp/windows/win32/api/winuser/nf-winuser-messageboxa
<br>

上記のページを見ると、`MessageBoxA()` の最後の `A` とか、`HWND` とかなんだ、となりますが、それは後々調べれば良いです。\
`std::ptr::null_mut()` や `as_ptr()` という見慣れないものもありますが、これも後で分かるようになります。
<br>
<br>

さて、エディタ上では赤線が表示されていてエラーがあることが分かりますが、とりあえず build してみましょう。\
**`cargo build` は、`Cargo.toml` があるディレクトリで行ってください。**

```
> cargo build
```
<br>

いろいろエラーが出ると思います。\
例えば、`MB_OK` のところに `not found in this scope` となっているので、これを解消してみましょう。

以下のページにある検索ボックスに `MB_OK` と入力してみてください。\
https://docs.rs/windows-sys/latest/windows_sys/?search=
<br>

そうすると、`windows_sys::Win32::UI::WindowsAndMessaging::MB_OK` が表示されます。\
リンクをクリックしてもいいですが、実は `MB_OK` の正式名称が、`windows_sys::Win32::UI::WindowsAndMessaging` である、ということが分かれば十分です。

`MB_OK` という言葉が突然出てきたんだけど、そんな言葉は知らない、ということで `not found` というエラーを表示しているのです。\
そのため、`windows_sys::Win32::UI::WindowsAndMessaging::MB_OK` が正式名称である、ということを教えてあげればエラーは出なくなります。\
正式名称を教えてあげるときには、`use` を利用します。

`main.rs` に、以下のように先頭に１行追加します。

```Rust
use windows_sys::Win32::UI::WindowsAndMessaging::MB_OK;

fn main() {
	let title = "rust-test\0";
	let message = "Hello, World!\0";
	unsafe {
		MessageBoxA(std::ptr::null_mut(), message.as_ptr(), title.as_ptr(), MB_OK);
	}
}
```
<br>

この状態で再び `cargo build` とすると、今度は `use windows_sys::...` の部分に、`use of ... crate 'windows_sys'` というエラーが表示されます。
これは、`windows-sys` という **crate** がなんなのか分からない、というエラーです。

**crate** とは、Rust における「開発単位」を指します。例えば、今私達が作っているのは、`rust-test crate` となります。
<br>

では、`windows-sys` という crate を使うことを Rust コンパイラに教えてあげましょう。

Rust コンパイラに教えてあげるには、`Cargo.toml` に記述を追加します。
`Cargo.toml` に追記をして、以下のようにしてください。

```
[package]
name = "rust-test"
version = "0.1.0"
edition = "2024"

[dependencies.windows-sys]
version = "*"
features = [
	"Win32_UI_WindowsAndMessaging",
]
```
<br>

`windows-sys` crate は大きな crate なので、いくつかに分割されています。その分割は `::` という記号で表されています。\
`windows-sys` の中の `Win32` の中の `UI` の中の `WindowsAndMessaging` の中にある、`MB_OK` を使いたい、ということなので、それを `features` で指示します。\
指示する場合には、`::` を `_` に変えて指示をします。
<br>
<br>

さて、もう一度 `cargo build` をしてみましょう。\
そうすると、今度は `MessageBoxA` のところに、`not found` というエラーが出ています。これは、さっき `MB_OK` のところで見たエラーと同じものですね。

さきほどと同じように、以下のページにある検索ボックスに `MessageBoxA` と入力してみてください。\
https://docs.rs/windows-sys/latest/windows_sys/?search=
<br>

`MessageBoxA` の正式名称が `windows_sys::Win32::UI::WindowsAndMessaging::MessageBoxA` と分かったので、`MB_OK` のときと同じように `use` を利用して正式名称を教えてあげましょう。

```Rust
use windows_sys::Win32::UI::WindowsAndMessaging::MB_OK;
use windows_sys::Win32::UI::WindowsAndMessaging::MessageBoxA;

fn main() {
	let title = "rust-test\0";
	let message = "Hello, World!\0";
	unsafe {
		MessageBoxA(std::ptr::null_mut(), message.as_ptr(), title.as_ptr(), MB_OK);
	}
}
```
<br>

ここで、１行目と２行目で `windows_sys::Win32::UI::WindowsAndMessaging::` が同じものであると気付いてください。\
`MB_OK` も `MessageBoxA` も、`windows_sys::Win32::UI::WindowsAndMessaging` の中にあるということなので、このような場合は以下のように１行で書くことができます。

```Rust
use windows_sys::Win32::UI::WindowsAndMessaging::*;

fn main() {
	let title = "TEST\0";
	let message = "Hello, World!\0";
	unsafe {
		MessageBoxA(std::ptr::null_mut(), message.as_ptr(), title.as_ptr(), MB_OK);
	}
}
```
<br>

`*` は、`windows_sys::Win32::UI::WindowsAndMessaging` の中にあるものを、これからいろいろ使いますよ、という意味になります。
<br>

もう一度、`cargo build` をしてみましょう。そうすると、ようやくエラーが出なくなりました。プログラムを実行してみましょう。
```
> cargo run
```
<br>

無事、**Hello, World! が表示された** と思います。お疲れ様でした！
